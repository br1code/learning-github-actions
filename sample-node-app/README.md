# Sample Node App

This is a tiny Node.js app created for GitHub Actions learning.

## Commands

- `npm install`
- `npm run build`
- `npm test`
- `npm start`

The app calculates a small sum and prints a friendly message using a small dependency.

`npm run build` creates a self-contained `dist` directory containing the app's runtime files and a production package manifest. This directory can be uploaded as a GitHub Actions artifact.
